FAQ

Frequently asked questions.

Clear answers about what Omega is, what it changes, and where the marketplace lives.

Does the website show the plugin database?

No. The plugin catalog is intentionally browsable only inside Omega in game. The public site explains Omega, its installation flow, and its security model.

Does Omega replace Dalamud?

No. Dalamud remains responsible for plugin installation, updates, disabling, removal, and lifecycle. Omega provides discovery and information around that process.

How do I install Omega?

Add Omega’s canonical PluginMaster URL to Dalamud’s Custom Plugin Repositories, enable it, then open /xlplugins, search for Omega, and choose Install.

Which repository URL should I use?

https://github.com/dalagab/omega/releases/download/omega-latest/pluginmaster.json

Who installs and updates Omega?

Dalamud does. The Omega repository only advertises the available package; installation, updates, disabling, and removal stay in Dalamud’s normal plugin lifecycle.

Does Omega tell me a plugin is safe?

No. Omega surfaces capabilities, findings, dependencies, provenance, and bounded evidence. Static analysis cannot prove that executable software is harmless.

Why isn’t the catalog on the website?

Because discovery belongs in the client where Omega can combine catalog information with your current Dalamud environment, compatibility, repository configuration, installed plugins, and installation choices.

Is Omega open source?

Yes. Omega’s source, workflows, and documentation are public. Third-party plugins remain the work of their own developers and retain their own licenses and policies.

Security, sources, and choice

Information for your decision.

Omega helps players understand the plugins they find. It does not decide what they may install.

Does appearing in Omega mean a plugin is endorsed, reviewed, or safe to install?

No. Discoverability is not endorsement, review, certification, or a promise that a plugin is safe. Omega presents the available context so you can make your own decision.

Why can an official Dalamud plugin receive a high-risk rating?

Official Dalamud status and a security rating measure different things. Official status is a provenance and publication-review signal. Omega's scanner reports the capabilities a package appears to use. A legitimate plugin may need native interop, game-memory access, hooks or detours, filesystem or network access, IPC, reflection, process APIs, or automated game actions. Those capabilities can be appropriate for the plugin, while still being important for a player to understand.

Does a high-risk rating mean a plugin is malicious or unsafe?

No. It means the package has powerful capabilities or findings that could cause more harm if misused, compromised, or implemented incorrectly, so it deserves greater scrutiny. If you do not trust a plugin, do not install it.

Why does Omega list plugins from third-party or unreviewed repositories?

Outside the official repository, repositories can be easy to find and add, but their behavior is not necessarily visible to a player. Omega does not discriminate against developers or repositories. It makes public plugins easier to discover alongside provenance and scanner context, helping players avoid accidental or uninformed installations.

Does Omega install third-party plugins automatically or bypass Dalamud?

No. You must choose to install a plugin. Omega asks Dalamud to perform the action, and Dalamud remains responsible for installation, updates, disabling, removal, and lifecycle.

What happens to plugins installed through Omega if I remove Omega?

Nothing. Plugins are installed and managed by Dalamud, not by Omega. Removing Omega does not remove or disable the plugins you installed through it.

Does Omega upload game data, personal data, or my installed-plugin list for scanning?

No. The marketplace does not scan your computer or upload your game data, personal data, or installed-plugin list to perform scans. Security intelligence is produced online from public plugin artifacts and metadata.

Does Omega execute, load, or install a plugin while it is scanned?

No. Omega is a marketplace, not a local scanner. The online security pipeline statically inspects public package artifacts as untrusted data without executing or loading their plugin code.

Where do the security findings in Omega come from?

Omega's online pipeline discovers public repositories and updates daily. When a package or its relevant code changes, the pipeline inspects it and stores detailed results in an evidence database. The marketplace uses a smaller, player-focused projection of that evidence.

Does Omega use AI or an LLM to scan plugins?

No. There are no models, LLMs, or AI verdicts in the scanner. Omega does the old-fashioned machine thing: deterministic rules, heuristics, static code and package inspection, dependency and advisory matching, and evidence records. The same input and scanner version produce the same result.

Can somebody manually change a plugin's findings?

Not through a per-plugin “make it safe” button. Findings and marketplace severity are generated from scanner evidence; people do not hand-edit individual results. The scanner, source feeds, and workflows are open source, so their rules can still change through normal code changes and review.

Can I inspect the evidence behind a rating?

Yes. When available, Omega can show the observed capabilities, dependencies, API usage, automation indicators, and specific findings behind a summary so that you can judge the result yourself.

Does Omega hide or block plugins with high-risk findings?

No. Omega informs rather than gates. You remain responsible for the software you choose to install on your account and computer.

How is the current marketplace rating calculated?

It is not currently a numerical points total. The scanner assigns findings severities such as Informational, Caution/Medium, High, and Critical. The marketplace rating reflects the highest-severity finding detected for that package, separately from confidence and repository trust.

How often are plugin records and security findings refreshed?
