Installation

Install Omega through Dalamud.

Add the Omega repository, then use Dalamud's normal plugin installer. Omega never replaces the install, update, disable, or removal flow you already know.

The helper script only adds the repository entry. You still choose Install in Dalamud.

Choose an install methodRead the installer source

Three simple steps

  1. 1
    Add the Omega repository.

    Use the helper script or Dalamud's Custom Plugin Repositories settings.

  2. 2
    Open /xlplugins.

    Search for Omega in the normal Dalamud plugin installer.

  3. 3
    Install and open Omega.

    Use /omega or /omg when you are in game.

Method 1

Use the helper script.

Best if you want an auditable, guided route. It validates the configuration, creates a timestamped backup, and adds or enables only the Omega repository entry.

  1. 1
    Close FFXIV and XIVLauncher.

    Avoid racing the launcher while it may write the same configuration file.

  2. 2
    Preview the change.
    powershell -ExecutionPolicy Bypass -File .\installer\Install-OmegaRepository.ps1 -WhatIfOnly
  3. 3
    Register the repository.
    powershell -ExecutionPolicy Bypass -File .\installer\Install-OmegaRepository.ps1

Method 2

Add it yourself in Dalamud.

Prefer not to run a script? Use Dalamud's usual Custom Plugin Repositories settings instead.

  1. 1
    Open Dalamud settings.

    Find the Custom Plugin Repositories or third-party repository settings.

  2. 2
    Add this repository URL.
    https://raw.githubusercontent.com/dalagab/omega/main/repository/pluginmaster.json
  3. 3
    Save the entry and open /xlplugins.

    Find Omega, choose Install, then open it with /omega or /omg.

What the script changes

One repository entry.

The script updates the Omega entry in Dalamud's ThirdRepoList, creates a backup before writing, and leaves unrelated settings and repositories alone.

Read every function and read/write scope on GitHub ->

What it does not do

  • Does not copy Omega DLLs manually.
  • Does not patch the game or launcher.
  • Does not create services or scheduled tasks.
  • Does not touch registry, PATH, or firewall rules.
  • Does not bypass Dalamud's normal install flow.
