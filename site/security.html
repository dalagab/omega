Security intelligence

Observation first.
Judgment after.

Omega surfaces capabilities, dependencies, provenance clues, changes, and risk indicators. It does not turn complex executable software into a misleading “safe” badge.

Capability

What can it appear to do?

Network, filesystem, native-code, process, automation, and game-state signals can provide useful context.

Evidence

Why was it reported?

Findings can carry bounded evidence so the player can understand what triggered the signal.

Uncertainty

What can’t the scan prove?

A clean scan does not prove harmlessness, and public source does not prove that a distributed binary was built from it.

Capability, not guilt

Useful software can use powerful APIs.

Network access is not automatically malicious. Filesystem access is not automatically malicious. Native code is not automatically malicious. Automation can be exactly what a plugin was designed to do. The meaningful question is whether those capabilities make sense for the software you are considering.

Omega provides signals and evidence. The player keeps the decision.

What Omega can surface

  • ✓ Exact scanned artifact identity and hash context
  • ✓ Observed capabilities and severity-classified findings
  • ✓ Managed dependencies and plugin dependency relationships
  • ✓ Bounded evidence and relevant call-site indicators
  • ✓ Package and dependency drift over time
  • ✓ Optional public source provenance, kept distinct from binary proof

What Omega cannot promise

  • × That a scan found every possible runtime behavior
  • × That “no findings” means safe
  • × That public source exactly matches a published binary
  • × That discoverability equals endorsement
  • × That using third-party plugins carries no account risk
  • × That static analysis replaces your judgment

Risk disclosure

Plugins run as software on your computer.

Third-party plugins can have extensive access to data available to the game process and resources available to the Windows user running the game. Plugin use may also place a FINAL FANTASY XIV / Square Enix account at risk, particularly where gameplay is automated.

A plugin being discoverable in Omega is not an endorsement or security certification.
