Installation

Install Omega through Dalamud.

Omega uses Dalamud's normal custom-repository and plugin-install flow. Add one repository URL, then install Omega from /xlplugins. Omega never replaces the install, update, disable, or removal flow you already know.

Install Omega

Three simple steps

  1. 1
    Add the Omega repository.

    Use Dalamud's Custom Plugin Repositories settings.

  2. 2
    Open /xlplugins.

    Search for Omega in the normal Dalamud plugin installer.

  3. 3
    Install and open Omega.

    Use /omega or /omg when you are in game.

Dalamud repository

Add Omega to Custom Plugin Repositories.

Open Dalamud settings, find Custom Plugin Repositories, add the URL below, and make sure the entry is enabled.

https://github.com/dalagab/omega/releases/download/omega-latest/pluginmaster.json
  1. 01Save the repository.

    Let Dalamud refresh its custom repositories.

  2. 02Open /xlplugins.

    Search for Omega and choose Install.

  3. 03Stay in Dalamud.

    Updates, disabling, and removal continue through Dalamud normally.

One supported path

Dalamud remains the installer.

Omega does not copy plugin DLLs, patch the launcher, or run a separate updater. The repository entry only tells Dalamud where Omega is published; Dalamud performs the actual installation and servicing.

After installation

  • Open Omega with /omega or /omg.
  • Keep Omega updates inside Dalamud.
  • The stable feed always points to an immutable versioned Omega package.
  • Older Omega repository registrations migrate automatically when eligible.
