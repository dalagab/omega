Installation

Install Omega.

Omega is installed through Dalamud. Register the Omega repository with the supplied script or add it manually using Dalamud’s normal custom repository settings.

Important: the helper script does not install Omega. It only registers the repository so Dalamud can perform the normal install, update, and uninstall lifecycle.

Method 1

Script-assisted registration

Best if you want a guided, auditable path. The script validates the config, creates a timestamped backup, and adds or enables only the Omega repository entry.

  1. 1
    Close FFXIV and XIVLauncher.

    Avoid racing the launcher while it may write the same configuration file.

  2. 2
    Preview the change.
    powershell -ExecutionPolicy Bypass -File .\installer\Install-OmegaRepository.ps1 -WhatIfOnly
  3. 3
    Register the source.
    powershell -ExecutionPolicy Bypass -File .\installer\Install-OmegaRepository.ps1
Method 2

The conventional Dalamud way

Prefer not to run a helper script? Add the repository using Dalamud’s normal custom repository interface.

  1. 1
    Open Dalamud settings.

    Navigate to the custom / third-party repository settings.

  2. 2
    Add the Omega repository URL.
    https://raw.githubusercontent.com/dalagab/omega/main/repository/pluginmaster.json
  3. 3
    Save or enable the entry.

    Then continue with the same normal Dalamud install flow.

Then install normally

Let Dalamud do the rest.

  1. 1. Start XIVLauncher / FINAL FANTASY XIV.
  2. 2. Open /xlplugins.
  3. 3. Search for Omega and choose Install.
  4. 4. Open Omega with /omega or /omg.

Exactly what the helper changes

One logical setting.

The script updates the Omega entry in Dalamud’s ThirdRepoList, creates a backup before writing, and preserves unrelated settings and repository entries.

It does
  • ✓ Validate the repository URL
  • ✓ Back up the config
  • ✓ Add or enable the exact Omega entry
  • ✓ Re-read and verify the result
It does not
  • × Copy Omega DLLs manually
  • × Patch game or launcher executables
  • × Create services or scheduled tasks
  • × Modify registry, PATH, or firewall rules
