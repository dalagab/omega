Features

More than another plugin list.

Omega puts discovery, provenance, compatibility, repository choice, and security context together in the in-game experience.

✦

Discover broadly

Omega can index official and third-party PluginMaster-compatible sources, presenting them through one coherent in-game marketplace.

⌁

Keep the source visible

Repository and project provenance remain part of the product view instead of disappearing behind a generic Install button.

↯

Choose repositories

When the same plugin exists from multiple known sources, Omega can show those sources and let the player choose which one Dalamud should use.

◎

Search like a storefront

Search, categories, authors, repositories, and searchable tags make a large ecosystem easier to navigate without exposing that database on the public website.

◇

Work offline gracefully

Omega retains a verified last-known-good local catalog when online refresh or validation fails.

⊙

Understand security signals

Static analysis can surface capabilities, dependencies, provenance clues, and risk indicators without pretending to certify a plugin as safe.

Provenance

A plugin is more than a title and an Install button.

Where did it come from? Which repository published it? Is there a public project page? Has the package changed? What does it depend on? Omega keeps those questions close to the decision.

⌁

Product provenance screenshot slot

Add product-provenance.png to the screenshots directory.

The product boundary

Omega discovers. Dalamud manages. You decide.

Omega does not replace Dalamud’s plugin lifecycle. Installation, updates, disabling, and removal remain Dalamud responsibilities. Omega gives the player a richer discovery and information surface around those actions.
