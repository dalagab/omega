# Historical prototype reports

These JSON files were produced by earlier Interdimensional Rift prototypes and
are retained only as development evidence. They are **not** current validation
artifacts. Several were produced with stale binaries / an older Dalamud shim and
must not be used to claim that the current source successfully executes API-15
plugins.

The forward implementation and validation gates are defined in
`../../docs/INTERDIMENSIONAL-RIFT-HARDENING.adoc`.
